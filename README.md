# Site Washington Rio Branco 4343

Site estático, responsivo e sem dependências de instalação.

## Publicação

Envie todo o conteúdo desta pasta para a hospedagem. A página inicial é `index.html`.

## Páginas

- `index.html` — apresentação e trajetória
- `propostas.html` — propostas e compromissos
- `apoie.html` — formulário de contribuição
- `voluntarie-se.html` — cadastro de voluntários

## Configurações

Abra `CONFIGURAR.md` para conectar o link de doação e o recebimento dos cadastros de voluntários. As duas URLs ficam concentradas em `config.js`.

## Antes de colocar no ar

Os formulários demonstram a experiência de cadastro, mas ainda não enviam dados a um servidor nem processam pagamentos. Conecte-os às ferramentas oficiais da campanha e complete CNPJ, dados legais e regras eleitorais antes da publicação.
